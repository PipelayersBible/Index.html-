TOP (Top of Pipe)Elevation: BOP + the pipe's outside diameter (OD), which is INV − wall thickness + OD. The app uses the real OD for the run's pipe type and size (15" SDR 35 is 15.30" OD, 12" ductile iron 13.20"); with no OD on file for the type or size, OD = pipe size + 2 × wall thickness.
