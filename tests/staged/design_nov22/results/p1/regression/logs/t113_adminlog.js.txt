Admin Access Log

This log lists changes to your company’s main records (runs, production, site log, job items, daily reports, permits and tickets) that didn’t come from someone using the app: changes the app’s operator made directly in the database (for example, to fix a problem), changes made with the server key, and some of the operator’s admin actions on your account (like changing your plan). It doesn’t cover stored photos and files, and records simply being read are not logged. Started November 17, 2026.
