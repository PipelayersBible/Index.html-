Admin Access Log

This log lists changes to your company’s main records (runs, production, site log, job items, daily reports, permits and tickets) that didn’t come from someone using the app: changes the app’s operator made directly in the database (for example, to fix a problem), changes made with the server key, and some of the operator’s admin actions on your account (like changing your plan). It doesn’t cover stored photos and files, and records simply being read are not logged. Started DATE.

3 entries:
DATE, T · Database console · Changed a run report (status, updated_at)
DATE, T · App owner tools · Changed your company’s plan
DATE, T · Server key (outside the app) · Added a daily report

Each finished day of the log is fingerprinted and time-stamped by outside time-stamp services, so a later change to a stamped day would show. The first day is time-stamped after midnight (UTC).
